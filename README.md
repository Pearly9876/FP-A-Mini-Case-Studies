# FP&A Mini Case Studies

A practical FP&A portfolio project showcasing financial analysis, driver-based forecasting, variance analysis, scenario planning, and management decision support through practical business cases.

## Project Purpose

This project is designed to strengthen my ability to move beyond financial reporting and develop stronger FP&A, commercial thinking, and decision-support skills.

Each case focuses on turning financial data into business insight and management decisions.

## Learning Roadmap

1. Financial Diagnosis
2. Business Drivers
3. Variance Analysis
4. Forecasting
5. Decision Support
6. Integrated FP&A

## Core Thinking Framework

Observation → Driver → Financial Impact → Business Implication → Recommendation
